# Brain Ring — Windows

Brain Ring oyunu üçün Windows proqramı (aparıcı paneli + oyunçu düyməsi).

## Yükləmək

👉 **[Son versiyanı yüklə](https://github.com/L-WalkerG/BrainringLW-releases/releases/latest)** — `BrainRing-Setup-x.y.z.exe` faylını açın.

- Quraşdırma admin icazəsi istəmir.
- Proqram yeni versiyaları **özü yükləyir və yeniləyir** — bir dəfə quraşdırmaq kifayətdir.
- Windows "Windows protected your PC" desə: **More info → Run anyway** (proqram hələ rəqəmsal imzalı deyil).

Bu repo yalnız quraşdırıcı faylları saxlayır. Mənbə kodu ayrıca private repodadır.
